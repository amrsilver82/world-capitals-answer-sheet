# Grid-free approximate location — prototype only

User reported fixed 20°x15° cells split Chad and other countries: neither adjacent cell is inherently the one correct answer. Avoid target-centered pre-highlight, which reveals the answer. Instead use the original Combined V2 large-flag quiz with a shared map below, and ask the user to tap an approximate position on land or sea. Draw a great-circle geodesic radius around the USER's selected point with 300, 500 or 800 km options (500 km default). The radius is a fair-comparison visualization, **NOT an agreed scoring threshold**. Previous answers stay numbered; full PC wheel and mobile gesture code inherited. No grading, no official GitHub record changes, no automatic target reveal.

For an official 195-country assessment, still need to define acceptable distance to country borders/land polygons, all acceptable disconnected island groups (including Kiribati), and how close neighboring countries share score tolerance, plus reference-data fidelity. Identical kilometre radius does not guarantee identical knowledge difficulty. Remains separate from old rigid-grid and exact-pin prototypes, and the official perfect 390/390 remains immutable.

## Radius per question (11-Oct-2026)

Each of the ten independent location choices now stores its own illustrative radius (300, 500 or 800 km) alongside the selected coordinate in browser-local state and the Build my reply output. When switching questions the radius menu follows that question. This preserves the user's intended approach of larger illustrative radii for tiny islands and smaller for larger visible countries **without claiming those are fair or official scoring rules**. Existing answers saved by earlier builds retain their coordinates; because earlier versions saved only a global radius, legacy entries default to 500 km rather than claiming to reconstruct previously chosen radii.

## More authentic map boundaries — Natural Earth 1:10m (11-Oct-2026)

Local prebuilt `../location/data/world-10m.json` is loaded after the original low-resolution atlas and replaces the 1:110m outlines at region/zoom scales (viewport width ≤600 SVG map units, corresponding to ≤150° longitude). The 1:110m map remains the fast global overview and offline/failed-fetch fallback. Boundary details are compiled from pinned Natural Earth 10m topology using `pilot/location/scripts/build_world_10m.py`, preserving the raw 10m border shapes without simplification except coordinate rounding to 4 decimal places; Germany upgrades from 35 to 2072 vertices. Offscreen-country bounding-box culling prevents drawing all 240 high-resolution features while zooming into one region. Natural Earth uses de facto borders, not universally agreed political boundaries, and is not cadastral precision. The approximate-location demo still has **no scores**.

## Fiji dateline seam correction (11-Oct-2026)

A real PC screenshot of Australia exposed repeated horizontal stripes at approximately 16–17°S. Diagnostic inspection of the 1:10m dataset identified eleven cross-world raw longitude jumps, including six in Fiji's islands near the International Date Line. The SVG renderer wrongly joined -180° directly to +180° using an unwrapped longitude axis. Fixed the atlas `path(poly,shift)` renderer to continuously unwrap longitude **within each polygon ring** before projection. This preserves the original detailed country border features and removes artificial global-width lines without changing the topology asset, selected user coordinates or scoring. CI regression verifies Fiji raw cross-dateline arcs exist but zero Fiji rendered segments/closures jump across half a world.
