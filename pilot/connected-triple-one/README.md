# One-country connected challenge — interactive concept demonstration

Public route: `/pilot/connected-triple-one/`

- Exactly one Tuvalu question using the immutable canonical country flag asset (`flags/canonical/675210ec5524.svg`), blank Country and Capital fields, then an interactive unlabeled world atlas.
- The written Country and Capital entries are made **before** the user chooses a geographical location; the atlas starts in world view and never jumps to the correct region. The user picks a region manually.
- No target label appears on the map before final evaluation. All marker anchors are fixed and anonymous; Pacific islands and European/Caribbean microstates have normal-size clickable circles. Clicking a land outline is supported for other mapped countries.
- The existing 177-country Natural Earth world background and 15 detailed target shapes are reused without changing them; this is **not yet a certified 195-country atlas**.
- The one-country demonstration is deliberately unscored and separate from Edition 3 and prior Issues #1, #2, #3. A 0–3 local preview result illustrates the combined format, not official scoring.
- Optional private Issue #4 stores completed practice attempts only. The existing restricted Issues token can be reused on the same origin if the player previously opted to remember it. No token is placed in source control. Without a connection, the demo remains playable but attempts are not synchronized.
- The static demo contains its own answer keys because there is no private live scoring backend. It is not appropriate as a tamper-resistant official exam without separate private validation.
- No approved changes to official scoring, no official new round, no hosting outside GitHub.

**Important evaluation goal:** Is this readable, fair, and satisfying for a country whose island geography is effectively microscopic at world scale? Inspect the ability to distinguish its neutral anchor from other Pacific anchors without target-specific clues.
