How the real championship will work

Each flag has one currency answer field. Country names remain hidden, including in the copied reply. Independent correct: +1 Pure / +1 Pure + Assisted. Correct after a requested clue: +0 Pure / +0.5 Pure + Assisted. Wrong: 0. Unassisted retries remain eligible for Independent credit. Clues are never automatic.

After every fully resolved batch, the real championship will save one atomic GitHub scoring commit, show the full original-answer review, category scores and cumulative totals, and provide Full Results and Next Batch links (or the final championship report after Batch 20). As in the old game, partial batch answers are never committed.

No GitHub login or token is required to use this preview. Draft entries stay only in your browser, and are separate from the four-category championship.
