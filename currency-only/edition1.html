How scoring works

Each flag has one selection: a repeated currency family, Other for typing, Clue for a hint, or Don't know to concede for 0 points. Only the currency is scored. The country names remain hidden, including in the copied reply. Only today’s accepted currencies count; historical currencies do not. Independent correct: +1 Pure / +1 Pure + Assisted. Correct after a requested clue: +0 Pure / +0.5 Pure + Assisted. Wrong: 0. Unassisted retries remain eligible for Independent credit. Clues are never automatic.

After every fully resolved batch, the championship will save one atomic private GitHub scoring commit, show the full original-answer review, category scores and cumulative totals, and provide Full Results and Next Batch links (or the final championship report after Batch 20). As in the old game, partial batch answers are never committed.
